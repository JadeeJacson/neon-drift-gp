# TOKYO · 東京シティ・スケープ

浏览器里的开放城市驾驶游戏：程序化生成的东京（涩谷十字路口、东京塔、晴空塔、东京湾、远郊山村），昼夜循环 + 霓虹夜景，可以观景、散步或开车。纯静态页面，零构建、零外部 CDN，直接用 GitHub Pages 托管。

在线游玩：<https://jadeejacson.github.io/neon-drift-gp/games/tokyo-city/>

## 玩法

| 玩法 | 说明 |
| --- | --- |
| 赛道计时赛 | 涩谷环线 → 都心环线 → 湾岸线，按顺序穿过闸门。完成上一条解锁下一条。按全程均速评定 🥇🥈🥉 奖牌。 |
| 地标打卡 | 涩谷 → 东京塔 → 湾岸台场 → 晴空塔 → 涩谷，路线自选，跟随导航箭头。 |
| 跑腿派单 | 取货 → 送达，全程倒计时。剩余时间决定星级，连续接单有连击加成（最高 ×2），撞车造成货损扣酬金。 |
| 自由驾驶 / 散步 / 观景 | 不计时，随便逛。观景模式有 6 个地标机位。 |

- **漂移分**：侧滑角 × 车速持续累积，撞车清零，完赛按分数加奖金。
- **车库**：奖金可购买 6 种涂装，以及引擎 / 轮胎 / 刹车各 3 级改装（真实改变操控参数）。
- **存档**：钱包、成绩、单圈纪录、奖牌、车库、设置保存在浏览器本地（`localStorage`，key `tokyo-city.save.v2`，自动迁移旧版成绩）。

## 操作

| | 键盘 / 鼠标 | 触屏 |
| --- | --- | --- |
| 驾驶 | W/↑ 油门 · S/↓ 刹车/倒车 · A D/← → 转向 · 空格 手刹漂移 · C 视角 · R 复位 | 左摇杆转向（上推油门、下拉刹车）· 右侧 油门 / 刹车 / 漂移 / 视角 / 复位 |

切到后台会自动暂停。

## 画质

设置 → 画质：`自动 / 流畅 / 均衡 / 高清`。

| 档位 | 像素比 | 阴影 | 辉光 |
| --- | --- | --- | --- |
| 流畅 | 1× | 关 | 关 |
| 均衡 | ≤1.5× | 1024，跟随玩家 | 开 |
| 高清 | ≤2× | 2048，跟随玩家 | 开 |

「自动」在触屏设备从流畅起步、桌面从高清起步，持续低于 32fps 会自动降一档。调试可用 URL 参数 `?quality=low|medium|high` 强制档位，`?debug` 显示帧率与状态。

## 目录

```
index.html          页面、HUD、面板样式，importmap 指向 vendor/three
src/main.js         启动、画质、主循环、各模块接线
src/game.js         玩法状态机（倒计时 → 进行中 → 结算）：赛道 / 派单 / 打卡
src/circuits.js     赛道、订单、打卡点等纯数据与几何（不依赖 three.js，可在 Node 里测）
src/progress.js     存档、奖牌、涂装、改装（纯数据）
src/play.js         观景 / 散步 / 驾驶控制器、碰撞、镜头
src/car.js          车辆物理与模型     src/traffic.js  车流、电车、人群
src/hud.js          驾驶 HUD、导航箭头、小地图     src/ui.js  标题 / 菜单 / 结算 / 暂停 / 车库 / 设置 / 说明
src/touch.js        触屏摇杆与按键     src/audio.js    引擎音、碰撞音、合成界面音效
src/env.js …        昼夜灯光、天空、辉光；layout / ground / buildings / landmarks / bay / signs / props / foliage 等建城模块
vendor/three/       three.js r180（本地化，避免 CDN 失效或被墙）
assets/             第三方素材，来源与授权见 CREDITS.md
```

本地运行：在仓库根目录 `python3 -m http.server`，打开 `http://localhost:8000/games/tokyo-city/`（ES Module 需要 http，不能直接双击打开）。
