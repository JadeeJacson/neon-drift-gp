# 灯塔纪元 0.9

在 0.8 量子纪元之上增加一层《星际拓荒》式的驾驶与航行外壳：3D 驾驶舱、苔原灯塔、营地生活细节、屏幕标记层与匹配速度提示。全部为原创实现与视觉；不改轨道、物理、量子与折叠航路的任何规则，发现点总数保持 47。

## 3D 驾驶舱（wilds.js）

- 第一人称驾驶时（`driving && !third`）放下仪表台、舷窗立柱与顶部遮阳沿，替换 0.8 的 CSS 立柱。
- 仪表台左右两块屏幕：左侧为星图意象（轨道环与目标点），右侧为实时速度 / 高度读数与推进条，节流 4 Hz 刷新。
- 屏幕下方 DOM 读数条同步显示速度与高度；指示灯、中央操纵台与柔和仪表灯为纯装饰。
- **Y** 随时开关；设置面板新增「3D 驯驶舱框架」复选框（默认开启）。触屏设备与照片模式自动隐藏。

## 苔原灯塔与营地生活

- **灯塔**：苔原山脊上的奶油色塔身 + 赤陶顶，灯室缓慢旋转两道光束（纯视觉，不指引航线、不改变任何判定）。塔身与基座有实体碰撞。建造时自动避开既有树木与岩石实例。
- **营地升级**：环形木栈道、四柱暖光串灯（两盏真实点光源）、三面小旗（缓慢摆动）。
- **进场灯带**：营地至着陆坪的十枚发光引导砖。
- **着陆坪泛光灯**：四角灯杆 + 向下照射的灯头与辉光，四枚赤陶角标。
- 灯塔是纯视觉地标，不注册为第 48 处发现点：47 处发现计数与全部 QA 基线保持不变。

## 星际拓荒式标记层

- **飞船标记**：徒步且距拾光号超过 60 m 时，屏幕边缘显示「拾光号 + 距离」。
- **黑洞 / 白洞标记**：25 km 内最近的折叠航路节点以琥珀色显示名称与距离（若它不是当前导航目标）。
- **匹配速度提示**：驾驶中朝导航目标的接近速度超过 22 m/s 且仍有距离时，屏幕上方出现「F（按住）匹配速度」。
- **相对速度箭头**：主导航菱形标记内新增随相对速度方向旋转的小箭头。
- 提示线补充 Y / N / P 常用键。

## 机制边界

驾驶舱、灯塔光束、灯带与泛光灯全部是视觉外壳；标记与提示只读取既有导航数据，不施加任何力。3D 驾驶舱在第三人称、触屏与照片模式下自动隐藏。灯塔不产生新发现点、不影响里程碑（8 项不变）。其余物理、轨道、量子、折叠航路边界与 0.8 完全相同。
