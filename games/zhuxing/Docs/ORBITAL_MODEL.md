# 轨道与物理模型

本文件描述沿用的 0.6 轨道底座；0.7 黑白洞与探针规则见 `FOLDED_SPACE.md`。

## 运动方程

使用米、秒及引力参数 μ，重力表面值给出 μ = g R²。恒星 μ = 2,000,000 m³/s²。行星相对恒星、卫星相对母星：

- n = sqrt(μ/a³)，M = n t。
- Newton迭代求 E − e sin(E) = M。
- r = ax · a(cos E − e) + az · a sqrt(1−e²) sin E。
- 解析求局部速度和加速度；卫星叠加母星的位置、速度、加速度。
- 固定倾斜轴自转：ω = 2π/P。自转周期160–660秒，轨道偏心率0.015–0.05。全部运行参数见 Web/orbits.js 的 ORBIT_LAYOUT。

天体轨道是分层受限双体模型，没有质心反冲、轨道互扰、潮汐锁定或自洽N体演化。自转不是扭矩积分。不会因为飞船靠近而改变行星轨道。

## 探索者与飞船

120Hz固定物理步长，半隐式Euler速度/位置积分。自由飞行受每颗天体及恒星当前中心的反平方引力，近表面与内部做半径钳制。落地先转入局部地表速度处理摩擦与碰撞，再恢复惯性速度。已接地物体按局部坐标随天体运输，离地时保留当地公转和自转速度。

建筑、箱形碰撞器、球形障碍、地表法线、仪器位置和地形采样使用一致的旋转。星环随环岚公转但不随固体表面刚性自转，其倾角保持固定。天气力、视觉雾、热流与星环碎石仍是游戏化内容，不是流体或粒子轨道模拟。

F 是有限推力速度匹配辅助：低于40米使用当地旋转速度，200米以上使用最近天体中心公转速度，中间平滑混合。不补偿重力，不保证悬停，不追踪导航目的地，也没有自动驾驶。

## 时间与存档

v6保存simTime、惯性坐标/速度、姿态、自转/轨迹状态及接地标志。恢复时先重建同一星系时刻，再恢复身体状态。暂停冻结星系时刻。回营地只重置玩家和飞船，不倒转宇宙。

旧v3/v5近地存档按旧天体坐标种子求局部偏移，再迁移到当前天体位置与转角，并补上运动速度。远离任一天体的旧深空位置无法可靠保留，采用苔原高空安全回收。旧存储键不覆盖删除。

## 移植说明

当前Godot目录是旧0.3底座。移植0.6时需先实现同样的simTime星历、局部地形采样、地表运输、碰撞变换与速度继承，再移植地标和存档。不能只让球体Mesh旋转而保留静态碰撞器。
