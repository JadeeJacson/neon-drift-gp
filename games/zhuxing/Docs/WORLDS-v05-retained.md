# 曦心星系 · 内容目录

1 颗恒星，5 颗行星，6 颗卫星；11 颗固态天体均可着陆、步行绕行。层级代表设计关系，不是公转模拟。

|---|---|---|---|---|

## 中心恒星

曦心：半径 620 m，弱引力源。745 m 热边界会缓冲推离，无死亡。不可进入或着陆。

## 8 处 G 仪器

热流强度、热井照明、测绘状态、极光三相位、减雾滤镜、风向测量、三组共鸣音、中继方向灯。状态可保存；不是任务或解锁条件。

## 建议首次路线

苔原营地练习 → 浮砾适应低重力 → 赤岬步行穿岩拱 → 炽砂尝试热流 → 霜镜滑冰与极光 → 雾灯菌林 → 环岚星环 → 鸣砂共鸣 → 静潮观景。余烬与玄砾可随时自由插入路线；没有强制顺序。
