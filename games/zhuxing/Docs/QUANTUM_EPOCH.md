# 量子纪元 0.8

在 0.7 折叠航路之上增加量子观测机制、深空视觉、经典科幻致敬遗迹、里程碑与触屏操作。对标《星际拓荒》的"观测改变现实"体验，全部为原创实现与文案；不是任何作品的移植或复刻。

## 量子观测

### 三枚碎晶

| 碎晶 | 位置 | 叠加锚点 |
| --- | --- | --- |
| 静默碎晶 | 苔原 | 3 处地表锚点 |
| 公理碎晶 | 玄砾 | 3 处地表锚点 |
| 菌梦碎晶 | 雾灯 | 3 处地表锚点 |

- **观测判定**：目标投影在相机视野内（含遮挡检查）即为"被观测"，坍缩为确定状态。
- **跃迁**：未被观测时每约 9 秒换到下一处锚点；被观测时永远安分。移动瞬间有轻微缩放与音效。
- **目击**：在碎晶跃迁后的 1.4 秒内重新注视它，记为"坍缩目击"，写入存档与里程碑。

### 观星者航标

三处随天体共动的锚点：苔原上空 850 m、霜镜上空 700 m、环岚上空 1100 m。

- 无人注视时每约 14 秒更换锚点；被注视时稳定。
- 趁它稳定时飞入环心（25 m 内）触发**量子跃迁**：出现在另一处锚点，方向被重新洗牌，速度大小保留（低于 12 m/s 补足）。飞船、宇航服与探针均可通过；5.5 秒冷却防连跳。
- 白洞只去一处；航标去所有它记得的地方。**U** 导航最近锚点；M 星图有量子分区；J 日志记录最近 8 次跃迁。
- 量子规则是游戏化机制：不是真实量子力学、退相干或多世界诠释的计算。

## 深空视觉（cosmos.js）

1. **星云背景**：程序化 fBm 星云穹顶，含一条淡色银河带；极低亮度，不干扰星野。
2. **大气辉光壳**：11 颗天体各自的菲涅尔 rim 光晕（艺术化近似，不是大气散射模拟）。
3. **天空色板**：每颗大气世界拥有专属天穹色与雾色，靠近时星野自动淡出。
4. **星冕**：曦心双层柔和日冕精灵，缓慢呼吸式脉动。
5. **高速尾迹**：飞船相对速度超过 55 m/s 时的凝结尾迹（纯视觉，无碰撞）。
6. **赤岬侧环**：赤岬新增一圈高倾角尘埃侧环与碎石（视觉，不可碰撞、不可采集）——本作最夸张的天体特征。
7. **太阳风**：距曦心表面 4000 m 内受到随距离指数衰减的径向推力（峰值 6 m/s²），HUD 实时显示强度。轨道模型与其余物理不变。

## 遗迹（lore.js）

- **玄砾 · 缄默方碑**：比例 1:4:9 的黑色石板（致敬克拉克《2001太空漫游》的原创方碑）。近处长久注视会得到一次微弱回应，写入存档。
- **静潮 · 银河档案环**：十二块记忆石与索引台（致敬阿西莫夫《银河百科全书》的原创档案）。G 循环三条档案摘录，摘录本身不解锁任何内容。

## 航行志与里程碑（goals.js）

- **航线志**：自动记录每颗天体的首次踏足时刻，J 日志可查。
- **8 项里程碑**：十一世界、全档案、双航路穿越、探针先行、量子旅人、坍缩目击、方碑回答、曦心近域。全部可选：不解锁内容、不设门槛、没有失败。
- **照片模式**：**C** 隐藏全部界面，**X** 保存 PNG 到下载目录。画布在渲染帧内同步抓取，无需保留绘图缓冲。

## 触屏（touch.js）

- 手机 / 平板可直接游玩：左侧虚拟摇杆（WASD），右侧动作键（上升 / 下降 / E / F），顶部快捷键（星图 / 日志 / 设置 / 黑洞 / 探针 / 量子），画面滑动转向。
- 触控被翻译成既有按键与鼠标事件，玩法逻辑零复制。键鼠仍是最佳飞行体验。

## 存档

保持 v6 轨道载荷与 v3/v5/v6 兼容；新增命名空间字段：`rifts`（0.7）、`quantum`（碎晶索引 / 航标锚点 / 跃迁记录 / 目击）、`lore`（方碑回应）、`goals`（里程碑 / 航线志 / 照片计数）。旧载荷缺失这些字段时从空记录开始，不清除旧发现。坏数据（越界索引、非法记录）整体拒绝。

## 机制边界

量子物体是预设锚点间的游戏化瞬移，不是波函数演化；观测判定是相机视锥 + 球体遮挡近似。星云与大气是程序化艺术渲染；太阳风是游戏化径向力。其余开普勒轨道、折叠航路、无死亡无燃料的设计边界与 0.7 相同。
