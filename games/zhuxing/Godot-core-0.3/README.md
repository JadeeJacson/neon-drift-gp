# 逐星 · Godot Core 0.3

真实可运行的 Godot 4.4.1 核心工程，**不是网页版的完整内容移植，也不是正式版**。

## 运行

1. 安装 Godot 4.4.1 标准版（不需要 .NET）。
2. 导入本目录的 `project.godot`，打开后按 F5。
3. 键鼠操作：WASD 移动/推进，Space/Ctrl 上下，E 登船/出舱，F 减速，Q/Z 滚转，V 驾驶视角，T 目标，R 重置位置，Esc 暂停/恢复。

起点在苔原北极，黄色飞船在右前方约 20 m。需要靠近至 9 m 才能登船。默认捕获鼠标；Esc 释放。R 立即返回营地，不带确认，因为此工程没有持久化存档或可清除的任务进度。

## 内容

- `main.gd` 程序生成三颗固定天体、共享引力、角色/飞船和调试 HUD。
- `player.gd`：CharacterBody3D、切向移动、跨极点朝向、跳跃与空中向上喷气。
- `ship.gd`：RigidBody3D、自定义重力积分、六向推力、有限辅助减速、角速度稳定、接地扶正、两套相机。
- 地表是平滑球体原生碰撞，树形标记仅作视觉参照。不是网页版高度场地形。

没有网页的观测站、岩拱、9 个地标、日志、可调设置、头灯、音效、存档和完整导航仪。第三人称遮挡/安全出舱空间查询仍待正式地图阶段完善。本次出舱继承线速度及出舱点的角速度分量。

## 测试

```bash
godot --headless --path . --fixed-fps 120 -- --test
```

根据实际引擎可执行文件名替换 `godot`。内置测试写出 `test-results.json` 并以 0/1 退出。覆盖站立、跨南极行走、登船、持续上升、惯性、三颗星球落地、出舱、暂停冻结。着陆用例会设置初始测试位置，不代表 Godot 中已自动完成一整段星际航行。

正常图形模式可加 `-- --capture` 导出预览图片后退出。Linux 验证使用 OpenGL Compatibility / llvmpipe；控制台仅出现软件渲染环境不能切换 V-Sync 的提示，没有脚本运行错误。图形与物理已分别检查，不是只做语法检查。
