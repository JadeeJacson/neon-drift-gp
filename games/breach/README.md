# BREACH 0.8.2 / 对照实验场

结构破坏实验游戏：在多层建筑上布置爆破，观察传力路径失效、碎片倒塌与整体侧倾。
0.6 版针对「炸成废墟后帧率锐减」做了系统级性能重构；0.7 版吸收 destruction-spike
的倒塌决策技术（分段触地释放、截面账、落地连锁、侧倾旋转/甩尾两大修复）；
0.8 版为场景包：烟囱/桥梁/停车楼/钟楼四个新预设 + 空袭剧本参数化。

## 开始游玩

用桌面 Chrome / Edge 直接打开 `BREACH-0.8.2.html`，无需联网与安装。

- **WASD** 移动 · **Shift** 疾跑(7 m/s) · **C** 下蹲(2 m/s)/滑铲(疾跑中按下)
- **空格** 跳跃(约 1m 高) · **Q / E** 侧倾 · 鼠标视角(设置里可调灵敏度)
- **左键** 开火 · **右键** 瞄准 · **1/2/3** RPG / 手雷 / 步枪
- **F** 步行 ⇄ 自由镜头(自由态 Q 降 E 升) · **B** 准星布点 · **V** 保存机位
- **Tab** 实验工具(导航 / 遥控方案 / 事件 / 设置) · **R** 重建 · **P** 暂停 · **.** 单步

## 0.8.2 新内容

### 废墟治理（PERF LAB 新开关：被压件固定/隐藏/消失）

- **被压判定（严格覆盖）**：停泊件正上方存在盖住它的停泊件（底 ≥ 顶+0.3m 且
  水平足迹相交）持续满延迟（3/6/10s）→ 按策略处理，爆炸解封时自动还原：
  - **固定(去碰撞)**：保留外观、摘碰撞、跳过处理——件在堆内，视觉无变化；
  - **隐藏(保碰撞)**：mesh 隐藏、碰撞保留（堆形最稳）；
  - **消失**：隐藏 + 去碰撞 + 尘雾提示（对象数收敛到底）。
- 实测（rc 双爆 20s，_scratch/breach-qa08-bury.cjs）：被压件 193-411 件，
  mesh 数 566→368/155（−35%~−73%）；单波物理耗时 −3~6%（gone 档）；
  QA 回归：411 件隐藏、再爆后 81 件解封还原可见、全程 finite。
- 可行性结论：**"静止几秒后固定/消失"完全可行且已上线**；"合并"（把碎块并成
  少量复合碰撞体）技术上也可行但收益窗口小（沉降堆每步仅 ~1.2ms），
  优先级低于治理开关，留待 street 规模验证后决定。
- 已知折衷：消失档的堆内部被挖空后，新碎块落下会轻微沉降填充；判定是
  启发式（格 2.5m），极端斜坡面理论上有误杀可能——用隐藏/固定档可零风险。

## 0.7 新内容

### 修复：侧倾的可见旋转从未累积（自 0.5 起的隐藏 bug）

- `topoStep` 此前每步把集群部件放到 `P+R(Δθ)(p0−P)`（增量角），每步回到静止位
  附近——内部 θ 正常增长，但画面里的楼在移交前几乎不动，移交瞬间"整簇炸开"。
  数值实验证实 θ=0.72rad 时部件仍在原位 0.12m 内。现改为累计角放置
  （速度场保留给接触采样，kinematic 积分恰好推进一步），倾倒为真实连续翻转。
- QA 断言：拆柱倾倒 18 模拟秒内顶点弧线位移 21.6m（旧实现 ≤0.5m）。

### 修复：倾倒移交时碎片向反方向甩（自 0.5 起）

- `topoStep` 的速度场公式算的是 **r×ω = −(ω×r)**（三个分量全部取反）：运动学
  阶段被绝对放置掩盖，但移交/段释放继承的就是反向速度——顶点在 handover 后
  上抛 ~8m、沿倒向反方向弹 ~10m（QA 数据留证：x −15.45→−4.95）。已修正为
  v=ω×r，QA 断言 `whipUpAfterHandover ≤ 1.5m`（实测 0）。

### 复合体分段释放（消灭"移交即散"）

- 倾倒集群按 2 层切成 L0 段（利用部件 `level` 字段）；整栋仍走重力矩 ODE 转动，
  各段以自身最低角点 ≤0.3m 几何触地为唯一释放条件，逐段脱离为动态刚体，
  速度继承自运动学速度场 v=ω×r。质量脱落后续段重算摆参数（I/W/com0）。
- 触地瞬间按预测冲击速度（段内最大向下速度，非接触采样）分 3 档（5/11 m/s），
  深度带内墙/板件（柱是骨架不入带）获额外冲量+损伤：取段内件数 9%/20%/34%、
  深度上限 1.2/2.6/2.6m（destruction-spike 碎裂带口径）。
- 移交（handover）只处理残余件，效果按剩余件数折减；硬上限 θ=2rad/25s。
- 新事件 `segment-released` / `segment-shattered`。

### 截面账：需求/容量监视与空中折断

- 倾倒相：逐层界截面计算达朗贝尔弯矩需求（M_j = |g·sinθ·(S1−s_j·S0) − α·(S2−s_j·S1)|，
  α 与摆 ODE 同源）vs 杆件 min(T,C)·(a_T+a_C) 容量（拉/压侧按截面质心分侧，
  |投影|<0.3m 中柱不计，无存活杆件退化为 0.08×完整容量）。0.1s 一评，
  ratio ≥ 1.0 → 截面折断、释放截面以上全部段（空中折断），事件 `section-failed`。
- 实测标定：完好集群全倒程 ratio 峰值 0.025（θ≈0 起步处）并随倒程衰减——
  连体摆动物理上不自断；折断只发生在截面受损（容量降档）场合，因果可读。
  强制链路验证：capacity=0.02 时倾倒 0.5s 内在受损层截面折断（ratio 1.27）。
- 站立相层截面聚合（同层承重杆件群体超载持续 0.35s → 整层折断）已实现并可
  `setCollapse({standing:{enabled:true}})` 开启，但**默认关闭**：开启后整层同折使
  上部结构成批转动态，rc 同场景物理耗时 ~1.8×，越出 0.7 的 1.1× 性能门槛（实测留账）。

### 落地连锁（废墟可再作用）

- 大质量落块（速度 ≥5 m/s、质量比 ≥0.35）撞击停泊碎块 → 解封 + 冲击损伤 +
  限次再碎（每件最多 1 次，spike chain 口径），与二次炸飞的既有解封路径共存。

### 性能（0.7.5 第一轮专项）

- **热点画像**（`ph()` 分桶，rc 3 埋点 30 模拟秒）：`ee.step` 物理占 83%+；
  成本全在**坍塌瞬变期**（0-10s：9-11ms/步、峰值 273 并发动态），沉降期
  仅 1.2-1.6ms/步。283 件停泊废墟本身很便宜——静态簇合并暂不做（收益窗口小），
  距离保真分级留给场景包规模（street 2188 部件）时做。
- **求解器迭代 9→7**（balanced 8→7、ultra 14→11、performance 6 不变）：
  瞬变窗配对两轮一致 −9%（6416/6708 vs 6811/7588ms）；迭代 4 明显变差
  （收敛差→抖动→更久不睡），不可再降。tolerance 提前退出（1e-7→1e-3/1e-2）
  与降摩擦（0.64→0.4/0）实测无收益或大劣，不采用。
- **活跃刚体预算**（spike P3 口径）：并发动态总量按档封顶（240/320/420/560），
  溢出排队、停泊归还预算后排水。注意：**预算一旦触发反而变慢**（悬空脚手架
  →碎块二次砸落→级联放大），故阈值只当极端场景的护栏、正常玩法不触发；
  单步释放限流实测劣化（~2×），已弃用。
- lS 撞击对缓存键改数值键（`min*1e7+max`，字符串键 GC 风暴同款教训）；
  `perfBreak()` / `setPark()` / `setBudgetCap()` 探针供回归与调参。
- 实测：rc 30 模拟秒全场景 0.7=8931ms vs 0.6=10278ms（ratio **0.869**）；
  配对交错双轮 0.983 / 0.861。

## 0.6 新内容

### 性能：废墟静态化回收（帧率锐减的主修复）

- 稳定判定：动态残骸速度低于阈值（或引擎已自睡）持续满档位延迟后，**强制入睡并转为
  STATIC 刚体**——引擎窄相跳过 static×sleeping 对、积分与唤醒级联全部停用，
  新碎块仍能正常压在静止废墟上；爆炸会先解封再施加冲量，废墟可被二次炸飞。
- 实测（本机 Chromium，rc 场景 3 发 charge 后 30s）：沉降期物理耗时 234→98ms/模拟秒（2.4×）；
  6 楼街道版三波空袭后废墟期 1953→680ms/模拟秒（约 3×）；爆破瞬间峰值两版持平（~1080ms，
  属爆炸本身开销）。CBD 场景三波后 1234/1516 件静态化，数值全程 finite。
- 结构求解节流：仅「结构脏（受击/释放）或有瞬态冲击」时 0.1s 全速，空闲 0.3s；
  awake 但未触结构的废墟不再触发全速求解。
- 碰撞对缓存：相邻部件碰撞过滤从每对 nodeIds/bondLinks 链式扫描改为数值键 Set 查表。
- GC 消减：物理步速度快照按 body.id 池化复用；裂纹层与诊断去分配；粒子池空闲时跳过
  矩阵/属性上传。
- 阴影按需重绘：可见状态无变化（静置观察废墟）的帧整张阴影图不再重画。
- 爆炸灯光/火球池化：灯光常驻（强度 0 待机），不再每次爆炸增删 PointLight 触发
  全场景材质重编译卡顿。

## 0.5 新内容

### 第一人称手感(移植自 RANGE)

- 指数加减速替代瞬时速度：行走 4.3 / 疾跑 7 / 下蹲 2 m/s，地面加速率 15/s、空中 4/s。
- 疾跑 + C 触发 0.72s 滑铲(初速 4+6·t m/s)；下蹲有头部遮挡检测，头顶被挡时无法站起。
- 跳跃 vy=6、重力 17，起跳后不被贴地跟随逻辑拽回；落地有 0.12s 缓冲下沉。
- 头部晃动(正比于速度)、落地缓冲、Q/E 侧倾 0.13 rad(带碰撞保护)、疾跑 FOV +5。
- 灵敏度随 FOV 缩放(瞄准时自动降低)，设置页新增灵敏度档位(0.5×–2×)。

### 整体侧倾倒塌(Topple Director)

单侧承重被摧毁后，剩余支承撑不住上部结构的偏心重量时，上部整体绕支承边铰线
向破坏侧加速倾倒(重力矩物理，非脚本动画)：

- **检测**：每 0.1s 评估各楼的「上部质心 ÷ 剩余支承边」偏心比，持续 0.3s 超阈才触发；
  支承仍足够的建筑(如核心筒未受损)不会误触发。
- **倾倒**：集群绕支承边以 I = 1.3·Σmr² 的转动惯量加速，θ 达到 min(0.6, atan2(h, 半跨)·0.92)
  或 7s 后移交 cannon 动态刚体，由撞击损伤系统收尾；移交瞬间附带尘幕、碎屑、隆隆声与镜头震动。
- 事件 `topple-start` / `topple-impact` 进入事件索引与审计导出；遥测行显示进行中的倾倒角度与件数。
- 倾倒过程中有 0.45s 周期的吱呀断裂声(距离衰减)。

### 性能

- **每帧视觉同步**：网格位置/颜色/实例矩阵从「每物理子步」改为「每渲染帧一次」，
  掉帧追帧时(单帧最多 5 子步)渲染工作不再 ×5。
- **碰撞代理缓存**：玩家行走的部件查询数组原地刷新数值，不再每帧重建数千个临时对象。
- 静置部件跳过矩阵比较；风力向量复用，不再逐件分配。

### 其他

- 风载有了声音：低通滤波噪声底噪，增益与截止频率随风速变化(25/45/65 m/s)。
- 行走脚步声(速度/下蹲影响音量与音高)。
- 帮助面板、菜单文案、遥测行更新；版本号与导出文件名统一为 0.5。

## QA 接口

`index.html?qa`（或任一版本存档）启用 `window.BREACH` 测试 API(与 0.4 兼容并扩展)：

| API | 说明 |
|---|---|
| `explode(x,y,z,kind)` | 在指定位置引爆(rpg/grenade/charge) |
| `walk(sx,sz,dt,{sprint,crouch,slide,jump})` | 驱动行走控制器,返回状态快照 |
| `walker()` / `setFoot([x,y,z])` | 读取/设置玩家状态 |
| `topple()` | 侧倾导演状态(runs/watch/starts/hands/lastErr + 原始参数) |
| `render()` | 手动渲染一帧,返回 drawCalls(隐藏标签页下截图用) |
| `stats()` / `step(n)` / `reset()` / `setPreset()` | 与 0.4 相同；stats 新增 parked/tier/constraints |
| `setQuality(name)` | 五档：performance/balanced/standard/ultra/auto |
| `raid()` / `raidStart()` | 空袭剧本状态（phase/wave/bombs/blasts）与手动启动 |
| `peds()` / `parked()` / `autoTier()` | 行人统计 / 静态化计数 / 自动档当前解析档 |
| `sections()` / `segments()` / `segStats()` | 0.7：截面 ratio 账 / 段状态 / 段释放与折断计数 |
| `collapse()` / `setCollapse(补丁)` | 0.7：倒塌参数读写（含站立截面账开关、监视容量系数） |
| `world()` / `solverModel()` | cannon-es 世界与结构求解器引用（回归探针用） |
