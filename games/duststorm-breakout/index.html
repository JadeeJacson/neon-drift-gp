穿过六片废土，到达避难所。撞击赚取资金，升级车辆；每次出发都会补满燃料、装甲与氮气。

D / →油门前进A / ←刹车，低速时倒车W / ↑ · S / ↓后仰 · 前倾，空中调整车身空格 / Shift按住释放氮气F / 点击场景发射手动导弹，点击可指定方向T切换自动导弹索敌（需先购买）R扶正脱困，消耗少量燃料和装甲Esc / P暂停 / 继续

丧尸会被撞飞，部分会挂在车前尖刺上数秒后甩脱。高速冲撞可触发肢解；连续击杀获得额外资金。脚手架更高、更密集，多层路线可驶入。足够冲量可撞碎支架；爆炸物可炸断附近立柱并让上层局部坍塌。碎片不会卡住车轮。S / 前倾可在入口保留走下层。导弹可炸毁支架，注意连锁爆炸。越过木箱、油桶和废车，留意落地姿态。手机使用屏幕底部按钮，可同时按住多个。
