# 2.3 测试说明

## 环境与运行

测试使用 Chromium + Playwright；并非所有平台实机覆盖。

```sh
python3 build.py
npm install --no-audit --no-fund
node tests/qa.cjs
node tests/v23.cjs
node tests/mobile-and-save.cjs
node tests/audio.cjs
```

浏览器默认 `/usr/local/bin/chromium`，其他机器请设置 `CHROMIUM_PATH`。Playwright 仅用于开发验收，游玩 `index.html` 无任何安装依赖。

## 范围

- `qa.cjs`：33 项检查，包含六区新对象生成、三类战术、补给一次性拾取、停靠/高速救援边界、测速门一次性判定、低速破甲/高速穿甲/爆炸穿甲、延迟爆炸、委托最终帧结算、成就与资金防重复、原有局部坍塌、平台高速驾驶及四区 20 秒导航回归。
- 导航回归隔离战斗伤害、丧尸与道具，用于验证物理未出现 NaN/Infinity 且车辆能够持续前进，不代表全部战斗场景不卡车或全关卡通关。
- `mobile-and-save.cjs`：13 项检查，包含战术 UI 操作、JSON 导出、错误 JSON 不覆盖、2.1 JSON 导入、刷新持久化、战术持久化、Chromium 实际多点触控派发（同时油门/发射）、释放触控、暂停冻结、横屏控件可见/不重叠、补给随结构坍塌下落，以及最后一帧委托补算。
- `v23.cjs`：25 项检查，覆盖 2.3 新系统：尸潮波次投放/新手保护/低速撕咬/低压关闭、投石者预警-抛掷-爆炸链、尖啸者动员、尸巢冲撞与爆炸清除、防线 Boss 生成/爆炸拆塔/守卫波、无尽流式延伸/过期清理/纪录结算/路线长度恢复、委托链两步推进与防重复入账、防线统计落库。含尸潮、防线、无尽、远征入口四张截图。
- `audio.cjs`：音频图建立、雨声滤波、暂停静音、天气关闭静音、总音效关闭静音。
- 桌面 1440×900；手机竖屏 390×844、横屏 844×390；额外实际触摸上下文使用 `isMobile:true, hasTouch:true`。截图包含车库、远征准备、成就、六图区分、救援、暂停、设置和结算。
- UI 截图与相关修正均做人工视觉检查；未做所有设备的完整性能、音色主观评价或全流程通关保证。

脚本运行会重写报告和测试截图，不修改交付文件内的默认初始进度；测试浏览器使用独立临时配置。
