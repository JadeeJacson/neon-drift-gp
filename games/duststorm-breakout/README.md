# 尘暴突围 2.3 · 尸潮觉醒

在 2.2 远征（战术配置、补给救援、特殊感染者、委托成就）基础上，让整条路「活」起来：后方追击尸潮、三类新变种、终点防线 Boss、无尽远征与委托链。

## 开始游玩

直接用现代浏览器打开 `index.html`，无需安装、联网或外部素材。推荐桌面 Chrome / Edge；手机建议横屏。部分手机文件预览器不执行 JavaScript，请使用浏览器或静态网页服务。

电脑：D / → 油门，A / ← 制动与低速倒车，W S / ↑ ↓ 平衡，空格 / Shift 氮气，F 导弹，T 自动索敌，R 扶正，P / Esc 暂停。手机支持多点触控，可同时按油门与发射。

从车库点击「远征准备」选择战术、查看本次委托和生存档案，或进入无尽远征。

## 2.3 新内容

### 尸潮觉醒：停车不再绝对安全

- 尸潮会周期性从车后方出现并追击；车速低于约 7 km/h 且被贴身时，追击者会撕咬装甲。减速停靠救援、原地翻车修整都变成了带时钟的决策——保持移动甩开它们，或用导弹清场。
- 第一区前 1700 单位为新手保护段，不投放追击潮。
- 设置中「尸潮追击压力」可关闭（低压模式）：回到 2.2 的平静节奏，无追击、无撕咬。默认开启。

### 三类新变种

- **投石者**：远程抛掷爆燃物，落点有橙色预警圈；炸伤车辆、也能引爆你的连锁。用导弹优先清掉，或加速冲过。
- **尸巢**：地面隆起的孵化巢，每隔数秒爬出感染者；冲撞三击或任意爆炸可摧毁（+$25）。
- **尖啸者**：粉红尖啸光环，会把周围普通感染者动员成疾行者。看到就先杀。

### 终点防线 Boss

- 每区终点前矗立一座真实结构的防线塔（可撞穿、可炸塌、连锁坍塌），塔上有 3 箱 TNT 弱点与守卫尸群。
- 引爆 TNT、撞穿核心甲板、或累计爆炸伤害均可瓦解防线；血条显示在 HUD 上方。
- 击破奖励 $400 + 区域×$300，计入生存档案「防线击破」统计。

### 无尽远征

- 远征准备页底部进入：无终点冲刺，地形/尸群/结构/补给/救援/测速门随行驶持续生成，难度随距离加压，身后内容自动清理。
- 燃料耗尽即结算；纪录（最远距离/最高击杀）保存在生存档案与存档中。地图样式沿用当前所选区域。

### 委托链

- 每项委托完成后自动下发「第二步」加码目标（约 1.6 倍目标、1.6 倍报酬），达成后再入账。行程条即时显示链式进度。

## 2.2 新内容

### 出发前：三个免费战术配置

- **长途侦察**：燃料容量 +15%；新增补给与原有补给箱的恢复量 +25%。离散弹药数向上取整，资源均不超过容量上限。
- **破阵先锋**：手动导弹爆炸半径 +18%；受到的爆炸伤害减少 20%。
- **飞跃专家**：氮气容量 +25%；落地伤害减少 35%。

战术不替代车型、护甲、推进器，不改变基础悬挂/碰撞公式。

### 途中：补给、救援与竞速

- 三种新增发光补给：油滴=燃料，十字=装甲，三枚弹头=弹药与氮气。驶近自动拾取，地面与第一层平台均有分布。平台破坏后，其上的新增补给会掉到地面。
- 蓝绿色 SOS 求救点：水平距离小于 155、接近地面、车速低于 12 km/h，累计停靠 1.2 秒完成接应。奖励 $180 和 3 点燃料。离开会逐渐衰减接应进度；驶过后仍能倒回救援。
- 测速门：前两区要求 58 km/h，后四区要求 70 km/h。首次越过立柱时判定，成功奖励 $140；未达标本次不能反复刷取。
- 行程条标出新增补给、救援和测速门。HUD 显示最近前方目标；上层路线经过救援点时提示前往地面。

### 战斗：三类特殊感染者

- **疾行者**：红褐色衣服与绑带，地面单位会向车辆追近。
- **重甲感染者**：钢盔与胸甲。低速碰撞先破甲，并有 0.7 秒受击间隔；再次撞击可清除。超过 430 世界单位/秒（约 65 km/h）或导弹/爆炸可以直接清除。
- **背罐感染者**：橙色背罐。死亡位置会出现警戒光环，0.7 秒后爆炸，可伤到车并引发原有爆炸/结构连锁。应保持移动或远程清除。
- 特殊感染者另有小额击杀奖励，统一计入远征结算。

第一段新手路程降低特殊敌人的组合压力，后续路段恢复混合分布。

### 长期目标：9 项委托、8 枚成就

- 每次自动接取 3 项委托，结算后按三组轮换，无需手动领取。
- 涵盖距离、击杀、补给、连杀、结构破坏、滞空、救援、测速与特殊感染者。
- 完成即时提示，奖励在结算时入账；最终一帧达成的目标也会核算。
- 8 项一次性成就，覆盖救援、补给、异变猎杀、飞跃、拆迁、竞速和累计委托。
- 生存档案保留累计统计与成就进度。新统计从安装 2.2 后的已结算行程开始，不追算旧版本没有记录的数据。

### 画面与声音细节

- 六区对应浮尘、冷雨、余烬、海雾、高空风沙与熔炉灰烬。
- 区域无线电、低油量/低装甲预警、委托回执和救援反馈。
- 补给悬浮、救援挥手、接应进度、背罐倒计时光环与特殊感染者外观。
- 制动尾灯、低耐久划痕与引擎舱烟气、受击边缘反馈。
- 本地合成的风沙/雨声底噪，随行驶变化，暂停/静音后停止输出。
- 天气可独立关闭；简约画质减少新粒子；尊重系统的减少动态效果偏好，停用新增漂浮/闪烁/动态天气。

## 存档与旧版兼容

沿用 `dustrun_save_v1` localStorage 键，保留车辆、购买装备、升级、区域解锁、资金和纪录。新增字段自动补齐。

**同一浏览器、同一站点来源**下可读取原存档。不同本地文件路径、浏览器或手机文件预览器可能隔离存档，不能保证更换文件后自动继承。

- 2.2：「远征准备」底部可以导出 JSON、导入 JSON；导入覆盖前需要确认。
- 导入接受 2.1 / 2.2 / 2.3 存档；先验证格式，失败不会清空现有进度。2.3 新增字段（尸潮开关、无尽纪录、防线/尸巢/变种统计）在旧档上自动补齐默认值。
- 2.1 没有导出界面。如需迁移，在旧游戏页面打开浏览器开发者工具，在 Console 输入以下只读命令，把结果保存为 `.json`，再到新版本导入：

```js
copy(localStorage.getItem('dustrun_save_v1'))
```

`copy` 是 Chrome / Edge 开发者工具 Console 的命令；不要在游戏源码中执行。若结果为 `null`，说明该地址下没有存档。先保留旧文件，不要重置进度。清理网站数据会删除本地存档，无云同步。

## 文件结构与构建

- `index.html`：完整离线发布版，包含所有 CSS / JS 和原有内嵌背景图。
- `template.html`：页面骨架。
- `src/game.js`、`src/styles.css`：2.1 基础系统（压缩构建产物）；仅在世界渲染中增加新增事件对象绘制入口。
- `src/expedition.js`、`src/expedition.css`：2.2 远征系统；以包装既有入口的方式集成，不替换车辆物理。
- `src/horde.js`：2.3 尸潮导演（追击潮/撕咬/低压开关）。
- `src/mutants.js`：2.3 变种感染者（投石者/尸巢/尖啸者）。
- `src/boss.js`：2.3 终点防线 Boss（结构塔/TNT 弱点/守卫波/血条）。
- `src/endless.js`：2.3 无尽远征（流式路段生成/过期清理/纪录）。
- `src/chains.js`：2.3 委托链（两步目标）。
- `src/meta.js`：2.3 归一化保护、设置开关、统一物理钩子与 QA 快照端点。
- `build.py`：无第三方依赖的构建脚本。修改源代码后运行 `python3 build.py`，重新生成发布版。直接修改 `src` 不会自动更新 `index.html`。
- `tests/`：浏览器测试脚本与实际报告。
- `previews/`：桌面与手机代表性状态截图。
- `ROADMAP-v2.3.md`：接手分析与 v2.3-v2.5 玩法路线图。
