## 4. 验证方式（本项目口径）

1. **语法关**：抽取 `<script>` 段 → `node --check`。**当前 PASS**（653 行）。
   抽取时注意第 128 行的 CDN `<script src=...></script>` 自带闭合标签，
   用 `grep -n "^</script>"` 才能定位到真正的脚本结尾（第 783 行）。
2. **服务关**：`node serve.mjs` → HTTP 200，完整 49,814 字节。**当前 PASS**。
3. **画面关（人工）**：需要真实浏览器 + 联网拉 three.js CDN。
   **由制作人打开 `http://127.0.0.1:8178/` 验收**——飞行手感、光照氛围、天体比例是否合适，
   这些自动化测不出（路线图 §4.5）。
4. **未做浏览器无头验证**：本作渲染依赖 CDN，而当前环境存在网络拦截，
   无头跑失败无法区分「作品有问题」与「拿不到 CDN」，故不纳入基线。

## 5. 已知限制与后续可选

- **three.js 停在 r128（2021 年）**，与 12 号用的 0.180.0 相差约 60 个版本。
  r128 的 `outputEncoding` / 光照单位与新版不兼容（`docs/versions.md` 练习期记录已注明），
  升级不是改个版本号的事，需整体迁移光照与色彩管理写法。**本轮不动**。
- **依赖 CDN，离线打不开**。若要离线化，可把 three.js r128 落到工程内并改成本地引用。
- **天体贴图为程序化生成**，与「还原」无缘，胜在零授权风险、零下载。
- 若要往「精美」推进，候选：真实行星影像贴图（NASA 公开域 / Solar System Scope，
  与 10 号已入库的太阳系纹理同源，见 `assets/SOURCES.md` §12.2）、
  更丰富的大气散射、星空 HDRI 背景。
