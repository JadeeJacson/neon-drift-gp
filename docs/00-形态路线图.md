6. **下载边界**：所有素材、引擎、工具只允许落在 `F:\Dev\Projects\game-lab\` 内。

## 5. 已沉淀的技术教训

### 5.0 Godot 工程初始化（2026-09-26 实测，06 工程建立时）

1. **`InputMap.add_action()` 不持久化**。Godot 4 的 InputMap 是内存结构，`add_action()`
   不会回写 ProjectSettings——即便随后调 `ProjectSettings.save()`，project.godot 里也
   **一个动作都没有**，`InputMap` 的改动随进程退出丢失。正确写法是
   `ProjectSettings.set_setting("input/" + name, {"deadzone": 0.2, "events": [InputEvent...]})`
   再 `save()`。**验证必须 grep project.godot**，别信脚本自己的「保存成功」打印
   （save() 返回 OK 但内容没变，就是这个坑）。
2. **`addons/` 目录不要改名**。模板的 `.tscn/.tres/.uid` 内嵌 `res://addons/<原名>/` 引用，
   改名要同步改所有引用文件。保持模板原目录名，只在文档里说明「这是什么」。
3. **第三方模板的 typo 要照抄**。Jeh3no 模板 `move_left_action = "play_char_move_left_ation"`
   （少了 c，见其 `player_character_script.gd:142`）。模板内部三处引用自洽
   （export 默认值 / default_input_actions 字典 / input_actions_list），
   所以注册 InputMap 时**必须用错名**，否则该键仍走运行期兜底分支并刷警告。
4. **`unzip -t` 必做**。本机断流会产出「看起来下完了」的半成品：particle-pack 断在
   1.98 MB（unzip -t 失败），完整包是 **15.0 MB**。`curl -C -` 能从半成品续传。
   教训：**文件大小本身就是完整性信号**——同站同类型包差一个量级时，先怀疑断流。
5. **`--import` 与 `--quit` 是两件事**：`--import` 只做资源导入（不跑场景），
   `--quit` 才加载主场景。两者都 EXIT=0 才算工程干净；只跑 import 会漏掉 `_ready()` 里的运行期问题。
6. **脚本模式下新建的 `InputEventKey` 会序列化出 `device:16`**，应改成 `-1`（任意设备）。
   手写/批量替换时检查这个字段。

### 5.1 素材站直链抓取（2026-09-26 实测）

- **Kenney**：详情页 `Download` 按钮是 lity 弹窗（`#inline-download`），真实 zip 直链
  藏在弹窗 DOM 里：`kenney.nl/media/pages/assets/<slug>/<hash>/kenney_<slug>.zip`。
  注意同一页面的预览图/音频是**另一个 hash 目录**，zip 的 hash 必须抓弹窗里的。
- **Poly Pizza**：搜索页 SSR 可解析（`/m/<id>` + `alt` 标题），详情页 `og:title` 给
  「标题 - Free Model By 作者」，GLB 直链 `static.poly.pizza/<uuid>.glb`，
  授权看页面含 `CC-BY` 还是 `CC0`。
- **Quaternius**：整站 JS 渲染 + itch.io api.js，curl 拿不到下载链接。
- **GitHub 发布物**：`codeload`/`releases/download` 直链 curl 稳定可用（Godot、模板）。

### 5.2 练习期教训（仍然有效）

- 耗时类指标在无头环境不可信；验证前实测渲染器，不要假设。
- 确定性物理可用于机器人自动跑关卡；手感量化成数字再做参数扫描。
- 工程化、自动化验证、性能指标都不能替代可玩性。验证脚本只说「有没有崩」，
  不说「好不好玩」。
