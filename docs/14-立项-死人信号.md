1. 枪模与亡灵模型偏粗（纯盒子拼装），机瞄时瞄具与准星只是近似对齐。
2. AI 只会直线冲（A* + 群体分离），不会绕后、不会翻越、受伤不改行为；难度只靠数量/血量/速度。
3. **没有僵尸模式的招牌机制**——电力谜题、武器强化、神秘盒子、回合特殊事件均未做，
   只有「尸潮 + 买枪 + 回血」这层骨架。
4. 命中判定是解析命中盒（躯干盒 + 腿盒 + 头球），贴身扫射会出现「看着打中没判定」。
5. 无 LOD 与遮挡剔除；本机实测约 57 fps〔需复核：仅一次采样，未测极端情况〕。
6. 音效即时合成，长时间连射听感偏薄，无混响与距离衰减模型。
7. 触屏只做了基础摇杆 + 按钮，未针对移动端调手感与 UI 密度。

## 7. 优化记录（2026-09-28 接手后实测修复）

动手前先用无头 Chrome + CDP 驱动 `window.DEAD` 真跑了一遍（脚本 `_scratch/verify14.mjs`、
`_scratch/probe14.mjs`）。下面三条都是**实测坐实的**，不是读代码猜的。

### 7.1 相机高度反复跳变 —— 同时造成「主角半身卡在地下」与「屏幕闪动」

- **根因**：`player.js` 相机段 `this.crouchK || 1` 的 **falsy 陷阱**。`crouchK` 递减到 0 时
  `0 || 1` 被判为 falsy 而弹回 1，眼高于是在 1.66 / 0.96 之间每 0.18 秒循环一次。
- **实测**：脚底 y 恒为 0，相机 y 却是 1.608 → 1.27 → 1.18 → 1.09 → **1.02** → 突跳回 1.66。
- **修法**：构造函数显式初始化 `crouchK = 0`，插值不再用 `||` 兜底。
- **复测**：相机 y 连续 8 次采样恒为 **1.66**，`crouchK` 稳定在 0。

### 7.2 探照灯硬切换 —— 「屏幕闪动」的另一半

- **根因**：`sky.js` 原为 `120 * (f > -0.55 ? 1 : 0.18) * (0.9 + rnd() * 0.15)`，三个毛病叠加：
  硬阈值让强度在 120 与 21.6 之间**瞬间**跳变（跌 84%）；每帧 `rnd()` 叠加随机噪点；
  `t * 37` rad/s（≈5.9 Hz）在 60fps 下接近奈奎斯特极限，产生 aliasing。
- **修法**：改低频（5.3 / 2.1 rad/s）+ `smoothstep` 连续映射到 [0.35, 1]，去掉每帧随机。
- **复测**：强度在 42–120 之间平滑渐变，不再有暴跌。

### 7.3 僵尸寻路卡死（P0，直接伤核心玩法）

- **根因**：`bots.js` 卡住判定 `moved < 0.02 * speed` 是**不含 dt 的绝对阈值**。
  60fps 下正常行走每帧只移动约 0.015 米（speed 0.9），小于阈值 0.03，
  于是**正常前进的僵尸被误判为卡住**并触发侧向绕行 → 原地来回震荡。
- **实测**：5 只里有 3 只距离十几秒不变（28.4→28.1、28.2→22.1 来回、15.8→15.6），
  玩家静止 48 秒 hp 恒 100——**六成尸潮压力是假的**。
- **修法**：阈值改为「实际位移 vs 期望位移（含 dt）」的 25%；`stuckT` 可衰减而非只增不减；
  长时间卡死时清空路径强制重算（原先只换边，换完还是走老路）。
- **复测**：5 只全部压到 0.3–1.0 米贴脸，玩家 hp 100 → 62（t=21）→ 0（t=26）。

**回归**：单测 24/24 + 33/33 全绿，`mapCheck()` 仍为 0 组穿模。

### 7.4 新机制：神秘盒子 + 电力开关（P1 首批）

按 COD 僵尸模式惯例补了两件标志性道具，全部复用现有「购买点」架构（`G.map.buys` +
`updateBuyZones`），并经 CDP 派发**真实 KeyF 键盘事件**端到端验证（`_scratch/test14-feat.mjs`）：

| 机制 | 数值 | 位置 | 实测结果 |
|---|---|---|---|
| 电力开关 | 1000 点 | 西南角 (-24, 18) | 扣点 ✓、`G.power=true` ✓、顶灯红→绿、拉杆立起 ✓、**重复按住不重复扣钱** ✓ |
| 神秘盒子 | 950 点 | 院落中东部 (12, 10) | 扣点 ✓、翻牌 3 秒（间隔 0.06→0.34s 渐慢）✓、结果武器自动入列并切到手上 ✓ |

配套改动：

- **灯杆聚光灯受电力控制**：合闸前整站只有月光与冷色环境光（灯杆是黑的），开电后才有聚光
  与「老化灯管」呼吸——「开电」从纯数值变成有视觉意义的目标，也构成 COD 式的前期紧张感。
- 翻牌状态机 `updateBoxSpin`：滚动名字渐慢、**最后一跳直接亮出结果**（避免「滚到的名字 ≠
  拿到的枪」的不一致）；翻牌期间底部提示由状态机接管，`updateBuyZones` 让位。
- 端到端数据：points 2000 → 1000（开电）→ 50（开盒），全流程无 console / page error。
