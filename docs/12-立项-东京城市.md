# 12 · 东京城市 3D 场景（TOKYO CITYSCAPE）

> **2026-09-27 立项**。制作人需求：「制作一个东京市的 3D 场景，尽量还原，包含白天和夜晚；
> 素材与技术栈可任选」。经制作人明确「可以不用管 Godot」，技术栈选 **three.js（Web）**。

## 1. 定位与硬约束的适用性

- 本项目是**场景 demo（技术验证/氛围作品）**，不是玩法项目——§0 硬约束 1「完整玩法循环」
  **不适用**（无开始/结束条件），由制作人在需求里明示为「场景」。
- 硬约束 2「素材优先」的适用方式：**地标与城市肌理全部程序化建模**（东京塔格构、晴空塔
  镂空旋成体、涩谷路口四角、街区/路网/招牌），未下载任何模型贴图。原因：可获得的免费
  素材（Kenney City Kit 等低包风格化件）与「还原东京」的目标风格不符；程序化在本题里
  不是「补缺」而是唯一能达成目标的路径，且结果可控、零授权风险。
- 硬约束 4「能看」：光照 + 天空/雾/辉光后处理 + 动态反馈（车流/电车/人流/大屏轮播）✅。
- 硬约束 5「可自动验证」：不走 `tools/verify.mjs`（那是 Godot 专用）；验证方式见 §4。

## 2. 技术栈与运行

| 层 | 选型 |
|---|---|
| 渲染 | three.js **0.180.0**（npm，MIT，版本钉死在 `package.json`） |
| 语言 | 原生 ES Modules，无构建步骤（importmap 直连 `node_modules/`） |
| 后处理 | EffectComposer + UnrealBloomPass + OutputPass（ACES 色调映射） |
| 服务 | `node serve.mjs [port]`（零依赖静态服务器，默认 8177） |

```bash
cd projects/12-tokyo-city
npm install        # three.js（首次）
npm start          # = node serve.mjs → http://127.0.0.1:8177/
```

操作：拖拽旋转 / 滚轮缩放 / 右键平移；HUD 按钮 白天·夜晚·昼夜循环 + 四个视角预设；
`N` 键切换昼夜。**默认首屏为夜晚**（霓虹是本作的第一印象）。

## 3. 内容清单（尽量还原的部分）

- **涩谷十字路口**：全向斑马线（四臂 + 对角）、109 圆楼（红色 109 招牌）、QFRONT 式
  大屏楼（双面轮播大屏）、SHIBUYA STREAM / TSUTAYA 意向楼、突出式竖霓虹招牌
  （canvas 绘制日文：居酒屋/カラオケ/ラーメン…）、自动售货机、过街人流。
- **东京塔**（333m，西南）：程序化格构（角柱/水平环/斜撑 22 段 ×4 面）、主展望台、
  天线、国际橙色 + 夜间泛光（含照亮塔基公园的点光源）。
- **东京晴空塔**（634m，东北远郊）：LatheGeometry 轮廓 + alphaTest 镂空格构纹理、
  双展望台环、塔基绿地。
- **城市肌理**：确定性生成的路网（主干道 28m / 支路 13m，第一个街区固定 95m 保证路口
  四角）、分区（涩谷核心 / 高楼群 / 中层 / 边缘低层 / 公园 / 塔基绿地）、山手线风格
  高架环线电车（绿色车体、夜间的窗灯带）、靠左行驶的车流（夜间前白后尾灯）。
- **昼夜系统**：自定义天空穹顶着色器（昼/黄昏/夜 + 星空 + 月亮盘）、太阳/月亮/半球光、
  距离雾、辉光强度、路灯 + 地面光池、窗户逐窗随机亮灯、招牌/大屏自发光——全部由一个
  `uDay` 因子驱动，3 秒平滑过渡；「昼夜循环」模式 110 秒走完一天。

## 4. 验证方式（本项目口径）

1. **语法关**：`node --check src/*.js` 全绿。
2. **运行关**：浏览器加载无报错（页面内置 `window.__errors` 收集器），主循环持续渲染。
3. **画面关（人工）**：日夜两态 × 航拍/街景/双塔共 6 个机位截图逐轮自查并修（本轮
   已完成 8 轮迭代，修掉：象限只生成一半、rAF 节流误判、过曝、幽灵路灯光、低层空带、
   大屏朝向装反、太阳方位角南北颠倒、金属材质无环境贴图发黑等）。**「好不好看」最终由
   制作人本人验收**——打开 `http://127.0.0.1:8177/` 按 N 看昼夜。
4. 注意：ZCode 内嵌预览里 rAF 会被节流到 ~1fps，属环境现象；本地浏览器正常。

## 5. 已知限制与后续可选

- 风格为**风格化低多边形**（程序化生成的结构正确性 > 材质照片感）； Wet road 反射、
  首都高高架、地铁、雨天模式未做。
- 若要往照片感推进，候选：真实地标 GLB（Sketchfab 需账号，由制作人下载）、HDRI 环境贴图、
  ambientCG 沥青/混凝土贴图替换 canvas 噪声、SSAO/SSR 后处理。
- 字体：招牌文字用 Windows 系统字体（Yu Gothic / Meiryo / MS Gothic → 回退 Microsoft
  YaHei），**不分发字体文件**；非 Windows 浏览器会回退到系统默认无衬线体，笔画仍可显示。
