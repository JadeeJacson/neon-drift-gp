## 4. 验证方式（本项目口径）

1. **类型关**：`node node_modules/typescript/bin/tsc --noEmit`。**本次 PASS（零错误）**。
2. **构建关**：`node node_modules/vite/bin/vite.js build`。**本次 PASS**（21 模块，295 ms）。
3. **视觉关**：`npm run verify:visual`（Playwright 视觉回归）、`npm run inspect:canvas`。
   **lab 本轮未复跑**——Playwright 需下载浏览器二进制，且当前环境有网络拦截。
4. **画面关（人工）**：`npm run dev` 后开 `http://127.0.0.1:5173/`。
   **由制作人实跑验收**——漂移手感、速度感、AI 压力曲线自动化测不出。

## 5. 已知限制与缺口

- **无 README**。工程内只有 `artifacts/design-brief.md`（设计简报，质量高），
  缺少「怎么跑 / 目录结构 / 调参入口」这类工程说明。建议后续补一份 README。
- **测试文件有两个是模板**：`tests/bot-playtest.template.ts` 与 `tests/visual-regression.template.ts`
  带 `.template` 后缀，说明**机器人跑分与视觉回归尚未真正接上**，当前只有 `tests/visual.spec.ts` 是活的。
- 物理是自定义街机模型（固定 1/60 步长），**确定性优于刚体引擎**，这点对自动化验证有利；
  但 AI 只沿中心线 + 横向偏移变化难度，行为层次较浅（与 14 号「AI 只会直线冲」是同类短板）。
- 音效标为「后期」（`M` 静音键已留位）。
- 依赖 Vite dev server 才能玩，**没有单文件产物**（与 14 号不同，14 可离线双击运行）。
