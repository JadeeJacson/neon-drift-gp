# 13 · 星际航行模拟器 Solar Flight

太阳系自由飞行模拟器：驾驶飞船在压缩尺度的真实太阳系中航行，完成 5 段导航任务后转入自由探索，
途中可点开任意天体查看真实天文数据。设计说明见 `../../docs/13-立项-星际航行.md`。

## 运行

```bash
node serve.mjs        # → http://127.0.0.1:8178/
```

单文件 HTML，直接双击 `index.html` 也能跑（three.js 走 CDN，需联网）。
`serve.mjs` 只是为了与 12 号保持一致的固定端口入口。

## 操作

- `拖拽` 转向 ｜ `W` 主推进 ｜ `S` 制动 ｜ `A`/`D` 侧移 ｜ `Q`/`E` 滚转
- `R`/`F` 升降 ｜ `Shift` 加力 ｜ `滚轮` 油门 ｜ `空格` 切断引擎
- `V` 视角（舱内/舱外） ｜ `单击` 查看天体 ｜ `M` 下一目标 ｜ `T` 轨道线 ｜ `N` 标签
- 顶部条：时间倍速与暂停；天体导航条可直接跳选目标
