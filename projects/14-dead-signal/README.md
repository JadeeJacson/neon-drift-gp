# DEAD SIGNAL · 死人会发电（COD 僵尸模式风格）

单文件 3D 网页游戏：一座被高墙围起的夜间前哨站，亡灵从三处闸口成批涌来，
玩家靠**回合制尸潮 + 点数抵墙购买 + 停火自动回血**这套《使命召唤》僵尸模式的骨架打下去。

> 技术栈与参考仓库 `riba2534/claude-opus-5-5-demo` 一致：**three.js（ESM，npm 安装）+ esbuild 打包内联成单文件 HTML**，
> 模型、贴图、音效全部程序化生成，产物零外部依赖。
> 玩法是对公开游戏类型的致敬实现，**代码与素材均为本工程原创，未复制参考仓库源码，不含任何原厂素材**。

---

## 一、怎么跑

```powershell
cd 14-dead-signal
npm install          # 装 three@0.169.0 与 esbuild
npm run build        # esbuild 打包 → dist/index.html（约 567 KB 单文件）
```

玩：直接**双击 `dist/index.html`** 即可（无需服务器、无需联网）。

开发（改完代码要重新 `npm run build`，用下面这个服务器可避开缓存）：

```powershell
npm run serve        # node serve.mjs 8131，带 no-store
# 浏览器打开 http://127.0.0.1:8131/
```

`dist/` 与 `node_modules/` 已在 `.gitignore` 中，克隆后跑一次 `npm install && npm run build` 即可完整还原。

## 二、操作与玩法

| 键位 | 作用 |
|---|---|
| `W A S D` | 移动 |
| `Shift` | 冲刺（有体力条，力竭短暂慢走；冲刺时不能开火） |
| `Ctrl` / `C` | 蹲伏（更准、更慢） |
| `空格` | 跳跃 |
| 鼠标左键 / 右键 | 开火 / **机瞄**（ADS，FOV 收窄、散布收敛） |
| `1` `2` `3` / 滚轮 | 主武器 / 手枪 / 军刀 |
| `R` | 换弹（霰弹枪为**逐发压弹**，再按一次可打断） |
| `V` | 军刀近战（在刀与主武器间切换） |
| `F`（按住） | **抵墙购买**：买枪 / 补满弹药 |
| `Esc` | 暂停（指针释放，点画面重新锁定） |
| `M` / `N` | 灵敏度 ±20%（写入 localStorage） |

**核心循环**：回合开始 → 从闸口成批出尸 → 清空全部亡灵 → 12 秒间歇（买枪补弹）→ 下一回合。
每轮亡灵血量约 +15%（第 1 轮 190 → 第 10 轮 668），第 4 轮起混入疯跑者。
点数来源：命中 +10、击杀 +60、爆头 +200、清轮 +300；开局送 2000。
掉血后 6 秒不回血，之后自动回满——**血量不靠药包，靠走位与卡点**。

│   └── ui/

浏览器 console 里的调试面 `window.DEAD`（也是自动化测试的抓手）：

| 调用 | 作用 |
|---|---|
| `DEAD.step(n, dt, visuals)` | **同步推进 n 帧**，不受后台标签页 rAF 节流影响；快进浸泡测试用 |
| `DEAD.mapCheck()` | 地图穿模自检，返回互相侵入的实心盒清单（当前为 `[]`） |
| `DEAD.perf()` | fps / 回合 / 点数 / 存活亡灵 / draw call / 三角面数 |
| `DEAD.fireOnce(n)` | 不走指针锁定，直接跑完整开火链（弹道→命中→结算） |
| `DEAD.round(n)` `DEAD.give('smg')` `DEAD.revive()` | 跳回合、发枪、复活 |

## 五、已实现与已知不足

**已实现**：完整对局流程（标题 → 分帧加载 → 回合对战 → 死亡倒地 → 结算统计 → 再来一局）；
4 把枪（M16A1 / SPAS-12 / MP5K / .44 马格南）+ 军刀，各自独立的散布、后坐曲线、距离衰减、换弹方式；
机瞄与 FOV 联动；冲刺体力；停火自动回血；亡灵 A* 尸潮与扑咬预警；点数抵墙购买；
程序化贴图/枪模/音效；触屏摇杆；动态准星与命中标记、受击方向指示、击杀信息流。

**已知不足**（按影响排序）：

1. **枪模与亡灵模型偏粗**：纯盒子拼装，机瞄时瞄具与准星的视觉对齐只是近似；僵尸四肢是整体枢轴摆动，没有真正的骨骼过渡。
2. **AI 只会直线冲**：A* + 群体分离能形成尸潮压力，但不会绕后、不会翻越窄台、不会因为受伤改变行为；难度只靠数量、血量与速度体现。
3. **没有僵尸模式的招牌机制**：电力谜题、武器强化、神秘盒子、回合间隔的特殊事件都没有做，只有「尸潮 + 买枪 + 回血」这一层骨架。
4. **命中判定是解析命中盒**（躯干盒 + 腿盒 + 头球），贴身扫射或僵尸前扑时会出现「看着打中没判定」。
5. **无 LOD 与遮挡剔除**，画质档位只切像素比与阴影。本机实测：中档、5 只亡灵同屏、12 次 draw call 时约 57 fps〔需复核：仅一次采样，未测 12 只同屏 + 开阴影的极端情况，且标签页切到后台会被 rAF 节流到 1 fps〕。
6. **音效是即时合成**，同一帧大量开火会叠加多个音源，长时间连射听感偏薄；没有混响与距离衰减模型（只有音量随距离的粗略映射）。
7. 触屏只做了一套基础摇杆 + 按钮，未针对移动端调手感与 UI 密度。
