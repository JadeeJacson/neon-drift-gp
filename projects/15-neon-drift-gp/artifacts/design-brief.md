# Neon Drift GP — 设计文档

## Design brief

- **玩家幻想（一句话）**：在霓虹蒸汽波都市赛道上漂移过弯、压制 AI 对手，刷出更炫的圈速。
- **目标手感**：街机漂移爽快感——夸张抓地、长漂移轨迹、速度感 FOV、碰撞短促反馈，而非拟真模拟。
- **主动动词**：漂移过弯（主）；次级：氮气爆发、路线选择（内线/外线）、失误后快速复位。
- **每 5–30 秒重复**：入弯刹车/起漂 → 出弯氮气 → 直道拉开/追近 AI。
- **1–5 分钟变化**：圈数推进、AI 节奏差、弯道组合变复杂、最后一圈压哨超越。
- **失败/学习/重开**：冲出赛道或被拉开距离 → 慢弯/错线可见 → R 快速重开或继续下一圈。
- **奖励与风险**：完美漂移充能氮气（奖励）；漂移角度过大掉速/撞墙（风险）。
- **高手差异**：更早起漂、贴弯心、氮气留给出弯，而不是直道乱按。
- **下一决策沟通**：弯道预告色带、AI 名次条、氮气条、最近圈速绿/红反馈。
- **本片非目标**：写实悬挂调校、开放世界、多人联网、车辆改装树。

## Core loop contract

> 玩家通过 **油门+转向+漂移键** 在压力（**倒计时 AI 名次 + 弯道惩罚**）下完成 **过弯与超越**，成功获得 **氮气充能与更优圈速**，失败导致 **掉速/撞墙/名次下滑**，可 **一按键快速再试**。

代码证明点：
1. 输入 → 漂移/转向意图（keyboard intents）
2. 目标可见 → 圈数、计时、名次 HUD + 世界起点线
3. 压力在首分钟 → AI 即时发车、首段 S 弯
4. 奖励改状态 → 漂移角度积分填氮气，氮气改极速/加速度
5. 失败可学习 → 撞墙减速有反馈；错失弯心可看见
6. 重开够快 → 3-2-1 发车或 R 重开本局

## Level / encounter plan

- **空间形式**：闭合都市环道（约 3 段直道 + 6–8 个可读弯），宽路肩+恢复区，中段标志性霓虹拱门。
- **相机**：第三人称追尾；不能看到车后盲区外的撞墙点（用弯前色带补偿）。
- **出生点**：并排 4 车（玩家+3 AI），第一决策 = 首弯选线。
- **首个威胁**：发车后第一个 90° 右弯（迟刹车可切内线）。
- **首个奖励**：出弯氮气垫 / 漂移满一段给的 boost。
- **地标**：中央蒸汽波巨日、两侧波普海报塔、终点霓虹门。
- **节奏**：每 20–60 秒一组弯型变化（高速扫弯 ↔ 急发卡）；直道作呼吸段。
- **恢复**：路肩减速但不出界硬惩罚；撞墙只弹开+掉速，不翻车。
- **模块化**：弯道按半径参数化；AI 沿中心线+横向偏移变化难度。

## Art direction（大胆混搭）

- **蒸汽波**：粉青霓虹、网格地平线、落日圆盘、VHS 轻微色差。
- **波普**：高饱和色块、漫画速度线、粗描边、撞色徽章。
- **动漫**：扁平高光车漆、描边轮廓、速度线 UI、角色化 AI 代号。
- **非写实 PBR**：MeshToon/MeshStandard + 鲜明 emissive，避免“灰色 demo”。

## Tech choices

| 项 | 选择 | 理由 |
|----|------|------|
| 栈 | TypeScript + Vite + Three.js | 脚手架默认、类型安全、迭代快 |
| 物理 | **自定义街机碰撞**（赛道 SDF/中心线 + 车-车圆盘） | 技能物理阶梯：街机手感优先于刚体拟真；无需 WASM |
| 手感 | 固定 1/60 步长 + 漂移状态机 + FOV/hitstop | 街机爽快可控 |
| UI | 自定义霓虹 HUD | 波普/蒸汽波语言，非仪表盘卡片 |
| 素材 | 程序化建模为主 + 可选 2D 生成 | 无 Key 也能完整可玩 |

## Controls

- `W/↑` 油门 · `S/↓` 刹车 · `A/D` 或 `←/→` 转向  
- `Shift` 氮气 · `Space` 漂移（手刹）  
- `R` 重开 · `Esc` 暂停 · `M` 静音（音效后期）
